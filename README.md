# 人事ラボ｜採用支援総合案内

人事ラボを入口に、運営会社・株式会社飛竜企画の実績と新卒／中途／アルバイト・パート採用向けのサービスを紹介する汎用ページです。

## ファイル

- `index.html`：PC・スマートフォン対応のWebページ
- `assets/`：ロゴ・イラスト類（HTMLから相対パス参照）
- `.nojekyll`：GitHub Pages向け設定

## GitHub Pagesの公開

リポジトリの **Settings → Pages → Build and deployment** で
`Deploy from a branch`、`main`、`/(root)` を選択します。
GitHub Pagesは認証付き社内限定サイトではないため、公開範囲に注意してください。

## 出典・公開前確認

- サービス名と事業領域： https://www.jinjilab.jp/service/
- 運営会社の会社概要： https://www.jinjilab.jp/company/
- 取扱求人メディア500以上／Indeedプラチナムパートナー：社内資料・社内記録を基に記載しており、公開前に最新状態を確認してください。
- 外部顧客の実写写真は使わず、会社紹介資料のロゴ・イラストと新規作成したイラストを利用しています。
- HTMLには `noindex,nofollow` が設定されています。SEO方針に応じて本番公開時に変更してください。

本ページはフォームを独自実装せず、人事ラボ公式の問い合わせ窓口へ誘導しています。
