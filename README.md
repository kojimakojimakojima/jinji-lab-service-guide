# 人事ラボ｜採用支援総合案内

人事ラボを入口に、運営会社・株式会社飛竜企画の実績と新卒／中途／アルバイト・パート採用向けのサービスを紹介する汎用ページです。

## 構成

- `index.html` — レスポンシブなWebページ
- `assets/` — サイト内で使うロゴ／画像
- `.nojekyll` — GitHub Pages向けの設定

## ページの内容

- 人事ラボを主役とするファーストビュー
- 運営会社・飛竜企画の実績／客観情報
- 新卒・中途・アルバイト／パート対応
- 求人媒体・広告、採用ブランディング／制作、RPO／アウトソーシング、採用DX／適性テスト／研修
- 1on1の課題抽出と「第二人事部」としての伴走姿勢

## プレビュー公開

GitHubの `Settings → Pages → Build and deployment` で `Deploy from a branch`、`main`、`/(root)` を選択します。

**注意**: GitHub Pagesは社内限定の閲覧制御ではありません。機密情報や顧客の実写写真を無許可で配置しないでください。

## 情報源と確認事項

- サービス名・事業領域：人事ラボ公式 https://www.jinjilab.jp/service/
- 会社概要：人事ラボ公式 https://www.jinjilab.jp/company/
- 取扱媒体「500以上」、Indeedプラチナムパートナー区分：社内資料／社内確認情報（公開前に更新状況を確認）
- 掲載画像：社内提供資料のロゴ・汎用イラストと新たに作成したイラストを使用。他社顧客の実写写真は使用しない

現在のHTMLには `noindex,nofollow` が設定されています。一般公開時は必要に応じてSEO設定を調整してください。
